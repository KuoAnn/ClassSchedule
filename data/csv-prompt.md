# 產生課表 CSV 的提示詞

把下面 `---` 之間的整段複製給 AI，連同你手上的課表（貼上的文字、PDF、截圖都可以），
它會回一份可以直接放進 `data/` 的 CSV。

欄位規格與 `scripts/spec.py`、`data/template.csv` 同步；改欄位時三份要一起改。

---

你是課表資料整理助理。請把我提供的課表整理成一份 CSV，**只輸出 CSV 內容本身**，
不要加說明文字、不要包在程式碼區塊以外的任何東西裡。

## 輸出格式

- 編碼 UTF-8（含 BOM），逗號分隔，第一列是表頭
- 表頭固定為下列 12 欄，**順序不可調換、不可增減**：

```
星期,開始時間,結束時間,課程名稱,師資名稱,師資國籍,教學語系,分類,級別,異動類型,異動老師,異動日期
```

- 一列 = 一堂課；同一時段有兩堂課就寫兩列
- 沒有值就留空（兩個逗號之間什麼都不放），不要填「無」「N/A」「-」
- 欄位內容本身不要出現半形逗號；需要並列時用全形頓號 `、`

## 各欄位規則

| 欄位 | 必填 | 規則 | 範例 |
|---|---|---|---|
| 星期 | ✔ | 只能是 `一 二 三 四 五 六 日` 其中一個字 | `三` |
| 開始時間 | ✔ | 24 小時制 `HH:mm`，補零 | `09:00` |
| 結束時間 | ✔ | 同上，且必須晚於開始時間（不可跨日） | `10:15` |
| 課程名稱 | ✔ | 原始課名，不要自己簡化或翻譯 | `哈達瑜伽` |
| 師資名稱 | ✔ | **只放名字**，不要夾帶括號註記 | `JAI` |
| 師資國籍 | | **一個中文字**，如 `印`（印度）`美`（美國）`日`（日本）；本國籍留空 | `印` |
| 教學語系 | | 授課語言代碼，英文授課填 `EN`；中文授課留空 | `EN` |
| 分類 | | 課程分類，原文照抄；沒有就留空 | `熱課程` |
| 級別 | | `初`／`中`／`高`；沒標示就留空 | `高` |
| 異動類型 | | `暫停` 或 `代課`，多筆用半形分號 `;` 分隔 | `代課;暫停` |
| 異動老師 | | 只有 `代課` 有值，`暫停` 留空但**位置要留著** | `Jen;` |
| 異動日期 | | 對應每一筆異動的日期 `M/D`，同一筆有多天用 `、` | `9/7;9/28` |

## 異動欄位怎麼配對

三個異動欄位以半形分號切開後，**同一個位置就是同一筆異動**：

```
異動類型   代課  ;  暫停
異動老師   Jen   ;
異動日期   9/7   ;  9/28
```

＝「9/7 由 Jen 代課」＋「9/28 暫停」。所以：

- 有幾筆異動，三欄就要有幾段（分號數量一致）
- `暫停` 那一段的異動老師必須是空的，但分號不能省略，否則後面全部錯位
- 同一筆異動有多天，日期用 `、` 串在同一段裡：`9/5、9/26`
- 沒有任何異動就三欄都留空

## 不要做的事

- 不要新增「教室」或任何表頭以外的欄位
- 不要把國籍或語系寫回師資名稱裡（`JAI（印籍）（EN）` ✗，拆成三欄 ✓）
- 不要自行翻譯課名或分類（英文對照表在程式裡，不從 CSV 讀）
- 不要用全形逗號、全形分號當分隔符
- 不確定的欄位一律留空，不要猜

## 拿到 CSV 之後

1. 存成 `data/<館別><年>年<月>月瑜伽課表.csv`（月份與館別由檔名推斷）
2. `./scripts/run.sh`
3. 看終端機的 **WARN**：新的分類／國籍／語系／級別不會擋住產檔，
   但會提醒你把正式的譯名與色票補進 `scripts/spec.py`
